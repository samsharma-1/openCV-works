# Development Roadmap

## Phase 1 — Camera

Deliver:

- Webcam input
- OpenCV window
- FPS counter

## Phase 2 — Hand Tracking

Deliver:

- MediaPipe hand landmarks
- Landmark visualization
- One-hand tracking

## Phase 3 — Gesture Engine

Deliver:

- Finger extension detection
- Open palm
- Two-finger gesture
- Three-finger gesture
- Pinch detection

## Phase 4 — Filter Engine

Deliver:

- Original
- Grayscale
- Sepia
- Warm
- Cool
- Vintage
- Vivid
- Negative
- Cinematic

## Phase 5 — Finger Filter Control

Deliver:

- Gesture-based filter selection
- Filter cooldown
- Pinch intensity
- On-screen status

## Phase 6 — RGB Controller

Deliver:

- RGB mode
- Channel selection
- Finger movement control
- 0–255 clamping

## Phase 7 — UX

Deliver:

- Gesture indicator
- Current filter
- Intensity meter
- RGB values
- FPS
- Help overlay

## Phase 8 — Testing

Test:

- Different lighting
- Different backgrounds
- Different distances from camera
- Fast hand movement
- No-hand condition
- Partial hand visibility
- Multiple hands
- Long-running sessions

## Phase 9 — Optimization

Target:

```text
20–30 FPS
Low latency
Stable gestures
Low CPU usage
```

## Phase 10 — Advanced Version

Possible additions:

- Face tracking
- AR face filters
- Background segmentation
- Gesture-controlled camera zoom
- Screenshot gesture
- Video recording gesture
- Custom LUT filters
- Shader/GPU acceleration
- Multi-hand interaction
